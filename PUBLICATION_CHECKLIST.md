# GitHub publication checklist / Чек-лист публикации

## Before publishing
- [ ] Confirm the repository name and public visibility.
- [x] Prepare a bilingual landing README and full English/Russian project pages.
- [ ] Confirm that the four source documents are the intended publication versions.
- [x] Selected CC BY 4.0 for original project materials; verify that all included materials are owned or cleared by the licensor.
- [ ] Confirm the preferred public contact method (do not publish a private email unless intended).

## After creating the repository
- [ ] Upload the contents of this folder to the repository root.
- [ ] Set the repository description in English.
- [ ] Enable GitHub Discussions.
- [ ] Add discussion categories matching `DISCUSSIONS.md`.
- [ ] Add repository topics, for example: `society`, `decentralization`, `mutual-aid`, `resource-accounting`, `social-design`, `governance`.
- [ ] Pin a welcome discussion explaining how to participate.
- [ ] Consider enabling Issues for specific corrections and proposals.

## Перед публикацией
- [x] Зафиксировать название репозитория и публичное позиционирование на двух языках.
- [ ] Проверить README на обоих языках.
- [ ] Убедиться, что четыре исходных документа являются нужными версиями для публикации.
- [x] Выбрана лицензия CC BY 4.0 для оригинальных материалов проекта.
- [ ] Определить публичный способ связи (не публиковать личную почту без такого намерения).

## После создания репозитория
- [ ] Загрузить содержимое этой папки в корень репозитория.
- [ ] Указать описание репозитория на английском языке.
- [ ] Включить GitHub Discussions.
- [ ] Создать категории обсуждений по `DISCUSSIONS.md`.
- [ ] Добавить тематические метки репозитория.
- [ ] Закрепить приветственное обсуждение с объяснением порядка участия.
- [ ] При необходимости включить Issues для конкретных исправлений и предложений.
